# mdori

A simple Markdown-to-HTML viewer with live reload and GitHub-flavored Markdown support. 

```plaintext
go install github.com/elh/mdori/cmd/mdori@latest
```

```plaintext
mdori path/to/file.md

usage: mdori [-addr host:port] [-no-open] <markdown-file>
  -addr string
    	listen address (default "127.0.0.1:0")
  -no-open
    	do not open the browser automatically
```

_WIP: Incomplete syntax support and styling, unstable._
